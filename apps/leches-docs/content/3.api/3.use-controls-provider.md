Returns the registered control record for a panel id and provides the shared store to descendants.

```ts
function useControlsProvider(uuid = 'default'): Record<string, LechesControlUnion>
```

Most applications only need [`useControls`](/api/use-controls) and [`<TresLeches />`](/api/tres-leches). `useControlsProvider` is useful for integrations that inspect the normalized controls directly.
