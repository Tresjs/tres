Renders the controls registered under its panel id.

```vue
<TresLeches
  uuid="default"
  :collapsed="false"
  :float="true"
/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `uuid` | `string` | `'default'` | Selects which registered controls the panel renders. |
| `collapsed` | `boolean` | `false` | Sets the initial collapsed state. |
| `float` | `boolean` | `true` | Uses a draggable floating panel when `true`; uses normal layout flow when `false`. |

## Slots

| Slot | Description |
| --- | --- |
| `default` | Custom content rendered after the generated controls. |

## Exposed value

The component exposes `controls`, a computed record containing the controls for its panel id.

## Built-in actions

Search and copy actions are available in the top-left corner while the panel is expanded.

| Action | Behavior |
| --- | --- |
| Search | Expands a **Search stuff** input and filters by control key, displayed label, or folder name. Matching controls remain inside their parent folder, which opens while the search is active. Press <kbd>Escape</kbd> or click the action again to clear the search. |
| Copy values for AI | Copies all current panel values as formatted JSON using stable control keys rather than displayed labels. Values outside a folder are at the root, named folders become nested objects, and button and graph controls are omitted. The copy is not limited by an active search. |

The actions enter after the panel expands, with a staggered right-to-left fade and bounce. This animation is disabled when `prefers-reduced-motion: reduce` is active.
